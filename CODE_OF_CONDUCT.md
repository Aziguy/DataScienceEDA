# Code de conduite

## Notre engagement

Nous nous engageons à faire de la participation à ce projet une expérience exempte de harcèlement pour tous, quels que soient l'âge, l'apparence, le handicap, l'origine, l'identité ou l'expression de genre, le niveau d'expérience, la nationalité, la religion ou l'orientation sexuelle.

## Comportements attendus

- Utiliser un langage accueillant et inclusif.
- Respecter les points de vue et les expériences de chacun.
- Accepter les critiques constructives avec ouverture.
- Se concentrer sur ce qui est le mieux pour la communauté.

## Comportements inacceptables

- Propos ou images à caractère sexuel, attention non sollicitée.
- Trolling, insultes, attaques personnelles ou politiques.
- Harcèlement public ou privé.
- Publication d'informations privées d'autrui sans autorisation.

## Application

Les incidents peuvent être signalés aux mainteneurs via une [issue privée ou un message](https://github.com/Aziguy). Toutes les plaintes seront examinées avec confidentialité.

Ce code est adapté du [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/), version 2.1.
